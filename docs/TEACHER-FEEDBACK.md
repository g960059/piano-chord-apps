## 2026-10-31：トップページの試作4案を見て

トップページの試作4案（A あそびば・B すごろく・C 2つの入口・D 音のへや）を、プレビューで見てもらったときの意見です。

### 1. 楽譜の音符：線の音符が「間の音符」に見える
- 音符の中が真っ白にぬられています。そのため、線の上にある音符なのに、線が音符の中で消えて、間の音符に見えてしまいます。
- 楽譜は正しく読めることが何より大事です。どのページにも出るので、いちばん先になおします。

### 2. むずかしさで分ける。全部を同じように並べない
- Ⅰ・Ⅳ・Ⅴは、受験をする小学生なら、かならず知っておいてほしい基本です。
- 増六やナポリの六は、明らかにレベルが高いです。基本と同じように並べると、わかりにくくなります。

### 3. 学ぶ順番（先生の考える地図）
**基本**
1. **長調のⅠ・Ⅳ・Ⅴ・Ⅴ7（属七）**：いちばん大事です。とても手厚くします。問題をたくさん作り、問題の種類（カテゴリー）も細かく分けます。
2. **短調のⅠ・Ⅳ・Ⅴ・Ⅴ7**：長調よりむずかしいところです。7番目の音（導音）に臨時記号がつくので、Ⅴ・Ⅴ7にはかならず臨時記号を書かないといけません。ここも同じように手厚くします。
3. **短調のⅤ9（属九）と、その根音省略＝減七**：短調のところでいっしょに教えます。

**そのあと**

4. **和音をもっと知ろう**：7つの和音（Ⅰ・Ⅳ・Ⅴ以外の Ⅱ・Ⅲ・Ⅵ など）、和音の形（転回形）、音のへだたり（何度という音程）。
5. **おわりかた（終止形）**
6. **曲につけてみよう（伴奏づけ）**

**毎日たのしむところ**

7. **耳のひろば**（和音の聴きわけ・ならびの聴きわけ）：ほかとは雰囲気を変えて、きらびやかに目立たせます。ランキングなどで、毎日のやる気につながる、ゲーム感覚でいちばん楽しいところにします。

**レベルアップしたい人へ（補足）**

8. Ⅱ7とドッペルドミナント → 副属和音 → ナポリの六 → 準固有和音 → 増六の和音（むずかしいので後ろ）→ 異名同音の読みかえ

### 4. 「減七と半減七」という分けかたはやめる
- 「半減七」という言い方は、ふつう使いません。
- 属七（Ⅴ7）は、長調でも短調でも同じ形です。ところが属九（Ⅴ9）になると、9番目の音が長調と短調でちがいます。そのため属九の根音省略は、短調では減七になりますが、長調では減七になりません。
- 「減七と半減七」のページ（今は変化和音の中）はなくして、その話は**短調のところ**に入れます。「なぜ短調の属九の根音省略は減七になり、長調ではならないのか」として教えます。

### 5. トップページの形
- 「ぼうけんの地図」（B すごろく案）の形でよい、とのことです。
- 「クイズだけあそぶ」という見出しは、何のことかわかりにくいです。耳のひろばを目立たせる話と重なるので、置き方は作る側にまかせる、とのことです。

### 6. 前にもらった意見（2026-10-30）
- トップページがお硬すぎます。「コース」という言葉が学校みたいです。小学生がとっつきにくいです。
- クイズだけをゲーム感覚でやる人もいます。クイズの色だけ変えるような、カラフルな感じでもよいかもしれません。
- ことばは、小学生〜中学生にわかるやさしい言い方にします。和声・ソルフェージュの専門用語はなるべく使わず、使うときはかみくだきます。

## 2026-10-31：5つの質問への答え（決まったこと）

### 1. Ⅰ・Ⅳ・Ⅴ・Ⅴ7 の目標
- **全部の調でできること**が目標です。
- **ハ長調 → 変ニ長調 → ニ長調 →…と、半音ずつ上げながら、Ⅰ・Ⅳ・Ⅴ・Ⅴ7 をパッパッとすぐにひける**ようになるくらいをめざします。
- ひけるようになるのは、**基本形まで**でよいです。
- 転回形は、**楽譜で答えられる**くらいでよいです。

### 2. 書きかた（和音記号）
- 「♭Ⅳ」のような書きかたは、コードネームのようになってしまうので使いません。
- **準固有和音（借用和音）は、小さい丸をつけて「◯Ⅳ」**のように書きます。
- 受験のための決まった教本はありません。**藝大レベルの音大の過去問**などを参考にします。

### 3. 減七の教えかた
- **「半減七」は、一度も出しません。**
- **「Ⅴ9の根音省略」**という言い方で伝えます。この言い方は、わかってもらわないと困ります。
- そのために、**「根音」と「省略」の意味から、しっかり教えます。**

### 4. レベルアップの順番
- **準固有和音 → ナポリの六**の順にします（Codex の案と同じ）。
- **増六の和音は、いちばん最後**にします。

### 5. 楽譜の音符
- **全音符**がよいです。
- 黒くぬると、四分音符なのか八分音符なのか、わかりにくい音符になってしまいます。
- 作る側の考え：いまの形は、ななめの白い丸で、2分音符の頭に近い形です。本物の全音符は、まわりが横長で、かたむいていません。中の穴だけが、ななめになっています。これに合わせて、穴は透明のまま（線が通って見えるように）描きます。

## 2026-10-31：本物の曲で楽曲分析（新しいアイデア）
- **コンクールで弾くような曲を使って、楽曲分析を穴うめのクイズでやる**と、楽しいし、いちばん役に立ちます。

- 曲の候補：
  - モーツァルトかハイドンのソナタから1曲
  - ベートーヴェンのソナタから1曲
  - メンデルスゾーンかシューベルトから1曲
  - ショパンから1曲
- 時代はロマン派までにします（近現代は無理）。
- **ショパンのスケルツォ第2番**は、増六の和音なども出てきてむずかしいので、最後の方に置きます。使う場所は次の3つです。

  - 変ニ長調に入ったところ（しばらく）
  - 展開部のようなところで、イ長調になったところ（少し）
