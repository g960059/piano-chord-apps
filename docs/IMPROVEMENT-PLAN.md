# 改善方針（2026-10-31）

この方針は、[先生からのフィードバック](TEACHER-FEEDBACK.md)をもとにしています。Claude の案と Codex（gpt-6-astra max）が独立に出した案をくらべて、1つにまとめました。

## 考えかた
- **「ページを並べる」から「できることを積み上げる」へ変えます。** 地図に出すのは、開いたページの数ではなく、「できるようになったこと」です。
- **基本と、レベルアップを分けます。** 基本は長調と短調の Ⅰ・Ⅳ・Ⅴ・Ⅴ7、それに短調の Ⅴ9・減七までとし、ここをいちばん手厚くします。増六やナポリの六などは、別の道に置きます。
- **耳のひろばは、毎日たのしく立ち寄る場所にします。** 学ぶ順番とは関係なく、いつでも遊べるようにします。
- **先生の順番と言い方を、いちばん大事にします。** 2つの案がちがうところは、先生の意見に合わせます。

- 和音クイズは、①（長調）と②（短調）の両方に出します。中身は、URL の設定（`keyset=major` と `keyset=minor`）で分けます。そのため、`PA.APPS` とはべつに、「島の中の課題」の一覧を持ちます。いまは、1つのページが入れる単元は1つだけです（`core.js:713` とテスト）。
- 「半減七」という言葉は、画面に出しません。長調の側は「長調の Ⅴ9 から根音をはぶいた形（減七にはならない）」と説明します。URL（`dim-halfdim.html`）と保存のキーは、そのまま残します。
- 「短調では、Ⅴ9 の根音をはぶくと減七」というように、どの調の話かをはっきり書きます。長調と短調をくらべるときは、同じ主音の調（ハ長調とハ短調）を使います。ちがうのは9番目の音（ラ と ラ♭）だけ、と見せます。

## トップページ
- **「ぼうけんの地図」（B すごろく案）をもとにします。** 先生の了承ずみです。
- **「クイズだけあそぶ」の並びはなくします。** わかりにくい、という意見があったためです。
- 上から次の順に並べます。
  1. つづきから（はじめての人には「長調の4つから始める」）
  2. **耳のひろば**のきらびやかなカード（「きょうの5もん」、続けた日数、自己ベスト）
  3. 基本の地図（①〜⑥）
  4. 「レベルアップしたい人へ」の、もう1つの地図（とじておきます）
- 地図の★は「開いた」だけでは増やしません。クイズの結果でつけます。
  - ★：見た
  - ★★：5もんやった
  - ★★★：自分でできた
- かえるが立つ場所は「いまやっている島」です。先生が途中の島を指定しても、まだ開いていない最初の島へもどらないようにします。

## Ⅰ・Ⅳ・Ⅴ・Ⅴ7 を手厚くする
- **問題のカテゴリーを分けます。**
  - はじまりの音を見つける
  - 音をたしてつくる（ド・□・ソ、Ⅴ に1つたして Ⅴ7）
  - 名前からけんばんでおさえる（いまのクイズ）
  - 楽譜を見て名前を当てる
  - 楽譜をえらぶ・なおす
  - まちがいを見つける
  - 似た和音をくらべる（Ⅴ と Ⅴ7、Ⅰ と Ⅳ）
  - ならびの「？」をうめる
- **進む順番は、次のとおりにします。** まねる → 一部をうめる → 自分でつくる → べつの出しかたでたしかめる → ならびで使う。1つの段階で、調・和音・答えかたを同時にむずかしくしません。
- **短調だけの練習を、べつに作ります。**
  - 7番目の音を見つける
  - 記号をえらぶ（イ短調のソ→ソ♯、ハ短調のシ♭→シ♮）
  - Ⅴ・Ⅴ7を完成させる
  - 𝄪 は後にまわす
  - 「短調はぜんぶ♯」とおぼえてしまわないように気をつけます。
- **1回は5もんにします。** 内わけは「いまの課題3・前の課題1・ふくしゅう1」です。まちがえたら、その手前の練習にもどり、数問あとにもう一度たしかめます。

## 耳のひろば
- 次の3つの入口を置きます。
  - **きょうの5もん**：終えると、地図の広場に灯りがともります。
  - **くらべて聴く**：まちがえた2つを、交互に聴きます。
  - **チャレンジ**：いまのもの。
- 続けた日数は、休んでも消しません。「今週3日できた」のように見せます。達成したときは、紙ふぶきなどで少しだけ華やかにします。
- ランキングは、ウェブではそのまま続けます。iOS の初版にはありません。1.1 以降で、Game Center などを使うかを考えます。
- Ⅰ・Ⅳ・Ⅴ は、1つだけ聴いても区別できません（どれも同じ長三和音）。役割を聴きわける練習は、「ならびの聴きわけ」でやります。
